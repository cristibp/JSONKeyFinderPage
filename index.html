Frequently Asked Questions

Got questions? We've got answers.

How does Ctrl+Click navigation work? ▼
JSON Key Finder registers a custom PSI reference contributor into the IntelliJ Platform. When you Ctrl+Click (or Cmd+Click on macOS) on any string literal matching a registered JSON key, the IDE seamlessly jumps straight to the line where that key is defined inside your JSON file.
Does it handle nested JSON objects and dot notation? ▼
Yes! If your JSON structure is { "auth": { "login": { "title": "..." } } }, you can search for either auth.login.title or simply title, and JSON Key Finder will accurately locate it.
Is my code or data uploaded to any cloud server? ▼
Never. The plugin is 100% offline. It contains no network libraries, no analytics, and no external endpoints. All ANTLR4 parsing and indexing is strictly confined to your local IDE process.
How do I pin a preferred / default JSON file? ▼
When opening the search panel (Ctrl+Alt+Shift+F), click the star icon (⭐) next to any file path in the results (e.g. en.json). That file will stay pinned at the top of your search results for that project.
